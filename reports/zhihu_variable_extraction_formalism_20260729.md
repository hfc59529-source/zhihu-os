核心变量：

- FV：权威理论开场，用书籍建立可信度。
- FV：反认知，先说形式主义不是蠢，而是理性应对。
- PD：上下级紧张关系。
- PD：强控制 -> 留痕 -> 免责 -> 共谋。

## 四｜爆款核心变量

1. 形式主义不是低效行为，而是组织风险和信任成本的产物。
2. 形式主义不是领导个人坏，而是层级组织的责任防御机制。
3. 高赞回答几乎都从“吐槽现象”推到“组织机制”。
4. 评论高的回答往往带有真实单位场景和身份背书。
5. 收藏强的回答都会给一个可复用解释框架。

## 四点五｜参数化变量卡

### 变量1｜现象反转解释

变量名称：现象反转解释

变量编码：FV-TEMP-01

变量大类：FV｜首屏变量

定义：首屏先承认用户对现象的直觉判断，再把“荒谬、低效、愚蠢、领导坏”改写为“理性防御、组织策略、生存动作或系统结果”。

生效机制：

```text
用户进入问题前已有强情绪和固定预期
↓
首屏反转预期，制造预测误差
↓
读者产生“原来还能这么解释”的认知奖励
↓
继续阅读以验证新解释是否成立
↓
提高停留、收藏和推荐信号
```

证据统计：

- 样本数：5
- 命中数：4
- 命中率：80%
- 来源：Top1、Top3、Top4、Top5
- 反例：Top2使用故事开场，不直接反转题设

证据等级：HYPOTHESIS

适用题型：职场吐槽题、组织问题题、管理不合理题、制度困境题。

触发条件：用户问题中存在强烈负面判断，如“为什么越来越严重”“为什么领导总搞这些”“干点实事不行吗”。

禁用边界：事实资讯题、法律风险题、需要直接回答流程或政策的题；读者需要信息而非认知反转时禁用。

Production Card 调用方式：默认调用。首屏必须完成“用户直觉 -> 反转解释 -> 主机制预告”。

Claude Prompt 调用方式：写入Prompt动作规则。遇到职场组织吐槽题，先检查能否做现象反转，不能只顺着情绪骂。

升级建议：新增到变量库，状态 `HYPOTHESIS`，后续采满10题后判断是否升级 EXPERIENCE。

### 变量2｜风险免责链

变量名称：风险免责链

变量编码：PD-TEMP-01

变量大类：PD｜推导深度变量

定义：把形式主义、留痕、开会、汇报、打卡等现象解释为组织中的责任防御链条：上级控制/检查 -> 下级留痕 -> 责任转移 -> 形式固化。

生效机制：

```text
组织存在追责和不确定性
↓
个体无法证明自己已经履责
↓
留痕、流程、会议记录变成责任证据
↓
形式动作比真实结果更容易被检查
↓
形式主义稳定存在
```

证据统计：

- 样本数：5
- 命中数：3
- 命中率：60%
- 来源：Top1、Top4、Top5
- 反例：Top2偏故事类比，Top3偏业务失控与中层自保

证据等级：HYPOTHESIS

适用题型：形式主义、背锅、责任边界、汇报留痕、流程合规、风险传导题。

触发条件：题目涉及“留痕、检查、汇报、群消息、打卡、台账、免责、出了事谁负责”。

禁用边界：纯个人成长题、纯薪酬题、纯人际关系题；没有组织追责或风险转移时不默认调用。

Production Card 调用方式：默认调用于形式主义/责任题；正文必须至少完成“现象 -> 责任证据 -> 风险转移 -> 固化”四步。

Claude Prompt 调用方式：写入Prompt动作规则。遇到留痕/流程/汇报题，优先检查风险免责链。

升级建议：新增到变量库，状态 `HYPOTHESIS`。

### 变量3｜信任成本替代

变量名称：信任成本替代

变量编码：PD-TEMP-02

变量大类：PD｜组织机制变量

定义：组织规模扩大、层级变多或协作链条拉长后，直接信任失效，于是用流程、日报、会议纪要、打卡、审批替代直接信任。

生效机制：

```text
小组织中贡献可被直接看见
↓
组织变大后贡献不可见、信息不对称
↓
管理者无法判断谁在真实产出
↓
流程和证据替代人际信任
↓
形式动作膨胀
```

证据统计：

- 样本数：5
- 命中数：2
- 命中率：40%
- 来源：Top1、Top4
- 反例：Top2强调流程反噬结果，Top3强调业务失控，Top5强调保平安

证据等级：OBSERVED

适用题型：大公司流程、跨部门协作、组织膨胀、管理失控、信任失效题。

触发条件：题目涉及“大公司、小公司对比、跨部门、多人协作、流程越来越多、领导看不见产出”。

禁用边界：小团队强信任场景、个人职业选择题、纯老板视角经营题。

Production Card 调用方式：条件调用。只有题目出现组织规模、流程膨胀或信任断裂时调用。

Claude Prompt 调用方式：留在参数库，不写入全局Prompt；由Production Card按题触发。

升级建议：继续观察，暂不直接进入默认参数。

1. 职场组织吐槽题，必须先把表层现象改写为组织机制。

只留在参数库，不写入全局 Prompt：

- 苏联工厂类比。
- 央企项目部具体场景。
