## L1入口定义

L1 不是互斥分类，而是代表样本入口。一篇内容可以同时命中多个入口。

| 入口 | 用途 |
| --- | --- |
| Top Performer | 找高表现特征 |
| Bottom Performer | 找失败边界 |
| Outlier | 找高收藏、低阅读、高收益、折叠等异常机制 |
| Recent Production | 观察新流程样本相对历史基线的位置 |
