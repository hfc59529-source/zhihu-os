## Attribution Check

### 1. 历史 observation

`data/revenue_observations.csv` 中当前只有一条记录：

```text
2026-09-03..2026-09-09：57 阅读 / 73 盐粒；累计 98 阅读 / 73 盐粒
```

结论：无法用历史重复观察确认它稳定高密度，只能确认“首次进入收益表时出现异常密度”。

### 2. 阅读口径差

```text
内容管理当前阅读：103
收益明细累计阅读：98
收益明细本期阅读：57
收益明细累计收益：73
```

可见差值：

```text
内容管理当前阅读 - 收益明细累计阅读 = 5
收益明细累计阅读 - 收益明细本期阅读 = 41
```

解释：

- 5 阅读差：内容管理实时阅读和收益明细更新时间不同，属于可接受延迟差。
- 41 阅读差：文章发布于 2026-09-05，但收益窗口为 2026-09-03..2026-09-09；理论上本期应覆盖发布时间之后全部收益阅读。这个差值提示收益明细的“本期阅读”与“累计阅读”可能不是简单同窗口口径，或存在收益资格/归因日切分。

因此不能直接把 `73 / 57` 解释为真实稳定 RPM。

## Model Implication

若后续排除口径错位，并且该样本继续表现为低阅读高收益，则原模型需要拆分：

```text
Question Context -> Distribution -> Engagement -> Revenue
```

升级为：

```text
Question Context -> Audience Composition -> Distribution -> Engagement -> Monetization
```

其中 `Audience Composition` 不等于阅读规模，而是“哪些读者被分发进来、这些读者是否更容易产生致知收益”。
