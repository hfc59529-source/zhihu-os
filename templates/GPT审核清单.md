## 最终结论

最终结论只能选择一个：

- PASS
- 正文问题
- 系统问题

## 归因规则

正文问题：

- Claude 没有执行选题包已有事实、问题边界或必要背景。
- Claude 没有执行已经存在且应调用的 ACTIVE 参数。
- 参数调用方向正确，但正文开头、推进节奏、场景、表达自然度、重复或收尾没有写好。
- 单篇正文出现表达失误、段落失衡、例子弱、开头弱、结尾弱。

系统问题：

- 参数库缺少本题必须依赖的规则，导致 Claude 无法正确调用。
- 参数库已有规则互相冲突，且不是 Claude 单篇误读造成。
- Claude 正文生产 Prompt 存在指令冲突、缺口或不可执行要求。
- 调用规则本身不能区分正文问题和系统问题。
- 同类问题连续 3 篇出现，且 GPT / 人工确认不是单篇正文执行偏差。

不得归为系统问题：

- 单篇开头、节奏、表达或收尾不好。
- Claude 遗漏已有参数。
- Claude 没有遵守已有选题包或 Prompt。
- 只有一次出现、尚未形成连续 3 篇同类证据的问题。

处理动作：

- 正文问题：退回 Claude 修改正文。
- 系统问题：交给 Codex 修复参数、Prompt 或调用规则。
- 无法判断：记录 Observation，不修改系统。

## 参数调用日志写入规则

参数调用日志以 GPT / 人工审核结果为准，不以 Claude 自报为准。

记录时必须区分：

- Claude 声称调用的参数。
- GPT / 人工确认实际生效的参数。
- GPT / 人工确认未生效、误用或遗漏的参数。
