## 字段定义补充

本模板不新增字段；以下内容由现有字段承载：

| 需要承载的内容 | 承载字段 |
| --- | --- |
| 题主显性问题 | `问题` |
| 题主真正困惑 | `读者真实困惑` |
| 解释覆盖哪些相关变量 | `因果追问链` 与 `分段施工说明 / 具体内容` |
| 因果解释追到哪一层 | `因果追问终点` |
| 最终让读者形成什么判断 | `唯一核心判断` 与 `结尾回收方式` |

字段执行规则：

- `读者真实困惑` 必须把题主显性问题翻译成正在困扰读者的真实判断困境。
- `因果追问链` 必须围绕同一个 Explanation Target（一致解释目标）展开，至少回答“为什么会这样 / 中间变量是什么 / 继续追到哪一层 / 这如何回到同一个读者真实困惑”。
- `因果追问终点` 必须说明解释停止在哪个可判断层，不得停在抽象词。
- `唯一核心判断` 必须直接回答该读者真实困惑，不得先写判断再用正文另造解释对象。
- `分段施工说明 / 推进关系` 必须逐段连接解释层级，确保每一段仍在回答同一个读者真实困惑。

## 后台审计报告

后台审计报告与 Claude 施工卡分开输出，不得放入 `===Production Card Begin===` 与 `===Production Card End===` 之间。

后台审计报告必须包含：

- ACTIVE结构引用检查
- 结构实例化检查
- 内容变量材料检查
- PD/RR/RE/BT/CR 参数检查
- 事实和安全边界检查
- 版本一致性检查
- 校验脚本结果
