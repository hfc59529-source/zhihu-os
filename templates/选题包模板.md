审核结果只允许四种：

- 驳回：已有参数可以解释，或证据不足。
- 合并：归入某个已有参数，必须填写 `Merge_Target`。
- 候选参数：用户批准进入 Candidate 前置流程，编号格式为 `Candidate-001`。
- 正式参数：极少发生，一般不得由单题直接进入，编号格式沿用参数库域编码，如 `PD-09`。

编号规则：

- 参数缺口：`Gap-001`
- 候选参数：`Candidate-001`
- 正式参数：`PD-09` / `RR-02` / `CR-01`

Source 可选值：高赞Top3 / 用户发布结果 / 人工审核 / 老师样本 / 历史数据库 / 评论区 / 数据复盘。

边界：本节只提交待审核观察，不新增 ACTIVE 参数，不自动修改参数库。重复次数用于证据累计，不等于自动升级。
