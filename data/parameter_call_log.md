# 参数调用日志

用途：记录每篇文章实际调用了哪些参数，以及发布后的表现，供 GPT / 人工审核和 Codex 后续参数迭代使用。

记录原则：

1. 只记录调用事实、审核归因和结果数据。
2. 不反推正文写法。
3. 不替单篇正文做表达优化。
4. 只有连续同类问题或明确系统问题，才允许回写参数库、Prompt 或调用规则。
5. 参数调用结果以 GPT / 人工审核为准，不以 Claude 自报为准。

模板：`templates/参数调用日志模板.md`

## Trigger Matrix 调用 Trace 字段（2026-08-09 起新增）

`production_variable_library.md`"生产前推荐格式"一节要求每次生产前输出 `Experiment ID / 推荐变量 / 实际激活变量 / 未激活变量 / 预期结果`，但本表历史上只有"Claude声称调用"一个自由文本字段承载，没有兑现这套结构化字段。

从 TRIAL Runtime 下的新 Run 开始，记录表列结构改为：

```text
Production ID | 选题编号 | 问题标题 |
Experiment ID | 推荐变量 | 实际激活变量 | 未激活变量 | 预期结果 |
GPT确认生效 | GPT确认问题 | 最终结论 |
阅读 | 点赞 | 收藏 | 收益 | 是否回写参数库 | 备注
```

`Claude声称调用`字段退役：其原有内容拆分为`实际激活变量`（结构化列表，对应 `Execution IR.triggered_rule_ids` 之外、`COMPILE` 实际激活的内容变量）和`备注`（原有自然语言说明，如仍有留存价值可继续写在备注里）。

此前记录（2026-08 上旬各条，见下表）不按新列结构倒填，按原样保留，不得事后编造 `Experiment ID / 推荐变量 / 未激活变量 / 预期结果` 这几个当时未记录的字段。
