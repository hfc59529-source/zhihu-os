# 参数调用日志

用途：记录每篇文章实际调用了哪些参数，以及发布后的表现，供 GPT / 人工审核和 Codex 后续参数迭代使用。

记录原则：

1. 只记录调用事实、审核归因和结果数据。
2. 不反推正文写法。
3. 不替单篇正文做表达优化。
4. 只有连续同类问题或明确系统问题，才允许回写参数库、Prompt 或调用规则。
5. 参数调用结果以 GPT / 人工审核为准，不以 Claude 自报为准。
