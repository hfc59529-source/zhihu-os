# EXP001 - 正文生成接口表达层优化

## 实验基本信息

**实验编号**：EXP-CLO-001

**实验日期**：2026-07-31

**实验目的**：判断 Claude 正文生成接口的问题主要来自表达层还是推理层。

## 实验假设

**H1（假设 A）**：Production Card 推理已经足够清晰，Claude 只需要改进表达方式。

**H2（假设 B）**：Production Card 推理不足，Claude 被迫进行额外推理补充。

## 实验设计

**唯一变量**：Claude 正文生成 Prompt
- A 版：按施工说明顺序展开
- B 版：自然重组信息

**固定变量**：
- Runtime 版本：ZH-RUNTIME-V3.0-TEACHER
- Production Card 模板：不变
- ACTIVE 结构：不变

## 成功标准

✓ B 版正文没有新增 Card 外的推理  
✓ B 版正文没有改变 Card 的核心判断  
✓ B 版正文因果链完整  
✓ B 版自然度明显高于 A 版

## 失败标准

✗ Claude 新增了 Card 没有的推理或框架  
✗ Claude 删除了 Card 中的关键论证  
✗ Claude 改变了核心判断  
✗ B 版与 A 版自然度无明显差异

## 实验结果

**状态**：INVALID（实验设计失败 - 变量污染）

**发现**：
- A 版：题目《领导任务》，B 版新增了"投资回报模型"框架，该框架 Card 未提供
- 问题：单纯改 Prompt 无法隔离表达层和推理层的效果
- 根因：Production Card 的推理层级本身不够清晰，Claude 在重新组织表达时被迫进行补充推理

## 后续建议

- EXP002 数据同样受协议漏洞影响，分析价值有限
- 建议改进实验协议后重新设计实验，确保在 Card 完全相同且推理清晰的前提下做表达变化测试
- 或者调整实验目标：先验证是推理问题还是表达问题，再针对性优化
