# 知乎账号画像快照

版本：PROFILE-V1.0

状态：ACTIVE

更新频率：关注来源、性别、年龄、地域半年更新一次；兴趣分布季度或半年更新一次；转化内容排行每月更新一次。

用途：指导选题方向、样本优先级和复盘解释，不直接改 Prompt，不新增 Production Card 字段。

## 执行边界

- 账号画像是长期基线，不参与每篇正文变量评分。
- 画像结论只能用于选题校准、案例选择、L1/L3 样本优先级判断。
- 关注转化排行可以触发 L3 深度事实包；性别、年龄、地域、活跃分层不单独触发 L3。
- 画像结论不得直接覆盖结构库、质量参数库或正文 Prompt。

## 关注者来源

状态：ACTIVE

当前信号：

| 来源 | 占比 |
| --- | ---: |
| 回答 | 64.2% |
| 个人主页 | 34.5% |

结论：粉丝主要来自回答，不是主页。日常资源继续优先投入知乎回答，个人主页不作为当前主要增长杠杆。

使用方式：进入平台变量证据和选题策略；不进入单篇 Production Card。

使用方式：仅作为平台背景统计；不进入 Prompt、不进入变量、不参与单篇复盘。

## 关注转化内容排行

当前样例：

| 内容 | 新增关注 |
| --- | ---: |
| 领导的威严怎么树立起来的？ | 37 |
| 什么事情是你当了老板才知道？ | 29 |
| 底层人与上层精英差距？ | 5 |

结论：关注转化排行是高价值复盘入口。

更新规则：每月统计新增关注 TOP20，建立关注转化排行榜。

复盘问题：

- 为什么能涨粉？
- 首屏是否强？
- 唯一主变量是什么？
- 使用了什么结构？
- 命中了什么机制？
- 提供了什么信息价值？

使用方式：新增关注 TOP20 默认进入 L1 样本；异常高关注转化样本优先进入 L3 深度事实包。

## 兴趣分布

当前样例：

| 兴趣 | 占比 |
| --- | ---: |
| 政治 | 7.8% |
| 情感 | 7.8% |
| 人文 | 7.6% |
| 职场 | 7.4% |
| 心理 | 7.3% |

结论：粉丝不是纯职场受众，而是组织、心理、人性、社会、管理混合受众。

选题校准：

- 不只写领导、管理、升职。
- 增加组织心理、社会运行、人性、制度、博弈类选题。
- 职场题优先写成组织、人性和制度机制，不写成单纯职场经验。

使用方式：建立受众兴趣画像，作为 L0 平台画像；季度或半年更新一次。

## 地域画像

当前样例：广东、江苏、北京、上海、浙江。

结论：受众集中在经济发达地区。

案例校准：优先使用互联网、制造业、大厂、民企、管理、老板、资源竞争等场景；减少东北小厂、农村、乡镇企业等与当前主受众不匹配的默认案例。

使用方式：只做案例选择基线，不参与每篇复盘评分。

## 性别画像

当前信号：

| 性别 | 占比 |
| --- | ---: |
| 男 | 76.6% |
| 女 | 23.4% |

结论：表达和案例默认偏男性职场受众。

表达校准：优先组织、权力、竞争、升职、老板、管理、资源、博弈；少用情绪、恋爱、家庭作为默认解释入口。

使用方式：只做表达和案例基线，不参与每篇复盘评分。

## 年龄画像

当前信号：25-40 岁约 81%。

结论：核心受众是基层员工、主管、经理、中层和创业者，不是大学生或退休群体。

默认用户画像：25-40 岁，一二线或经济发达地区，企业员工、管理者、创业者，偏男性。

使用方式：用于选题准入和案例选择；不新增 Production Card 字段。
