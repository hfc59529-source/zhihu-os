# 生产状态机与交接规范

状态：ACTIVE
日期：2026-08-01

## 核心规则

任何角色完成本阶段后，只能更新状态并交接给下一责任角色，不能替下一角色继续决策。

状态只有在该阶段的必要输出和校验证据全部存在时，才能向下流转。

## Codex 正文禁写边界

Codex 只负责 Production Card、QA、审核记录、状态归档、Final Validation 和发布记录，不负责正文写作或正文修正。

Codex 禁止直接创建、改写、润色或替换以下正文类文件的正文内容：

- `Draft-v1.md`
- `Article-v*.md`
- `Article-Patched-v*.md`
- `Article-Final.md`
- `Release-v*.md` 中的正文段落

Codex 发现正文问题时，只能输出审核问题、证据、风险、修正目标和下一责任角色，不得直接给出已完成的正文替换结果。若需要 Patch，状态必须流转到 `READY_FOR_PATCH`，由 Claude / 写作角色执行正文修正。

Codex 允许编辑的文件范围：

- `Card-v*.md`
- `Codex_QA.md`
- `Audit_Report.md`
- `Decision_Log.md`
- `Final_Validation.md`
- `Comparison_Report.md`
- `data/production_ledger.md`
- `runtime/logs/*.jsonl`
- `data/Publish_Queue.md`

`Release-v*.md` 只能在用户验收通过后，由 Codex 从已验收正文同步生成或确认；不得在 Patch 未完成、Final Validation 未通过、用户未验收时作为正文修正载体。

## 状态表

| 阶段 | 状态 | 负责人 | 主要输出 |
|---|---|---|---|
| 1 | 生产卡完成（CARD_READY） | Codex | Production Card |
| 2 | 正文完成（DRAFT_READY） | Claude | Draft-v1 |
| 3 | QA通过，待人工审计（READY_FOR_AUDIT） | Codex | QA结果、待审正文 |
| 4A | 审计通过（AUDIT_PASS） | GPT / 人工 | Clean Pass 结论 |
| 4B | 审计发现问题（AUDIT_ISSUE） | GPT / 人工 | Audit Report、裁决 |
| 5 | 待修复（READY_FOR_PATCH） | Claude | 已确认修复任务 |
| 6 | 修复完成（PATCH_COMPLETED） | Claude / Codex归档 | Patch 后正文、变更记录；Codex 只归档不改写 |
| 7 | 待最终验证（READY_FOR_FINAL_VALIDATION） | GPT / Codex | Final Validation 输入 |
| 8 | 待用户验收（READY_FOR_USER_REVIEW） | 用户 | 最终正文阅读与验收 |
| 9 | 可发布（RELEASE_READY） | Codex / 用户 | Release-v1、用户验收结论 |
| 10 | 已发布（PUBLISHED） | 用户 / Codex记录 | 发布链接、发布时间 |
| 11 | 数据已回收（DATA_RECORDED） | Codex | Comparison Report 更新 |

## 无问题链路

```text
READY_FOR_AUDIT
↓
AUDIT_PASS
↓
READY_FOR_FINAL_VALIDATION
↓
READY_FOR_USER_REVIEW
↓
RELEASE_READY
↓
PUBLISHED
↓
DATA_RECORDED
```

即使审计是 Clean Pass，也不能从 AUDIT_PASS 直接跳到 RELEASE_READY。必须经过 Final Validation。

## 有问题链路

```text
READY_FOR_AUDIT
↓
AUDIT_ISSUE
↓
READY_FOR_PATCH
↓
PATCH_COMPLETED
↓
READY_FOR_FINAL_VALIDATION
↓
READY_FOR_USER_REVIEW
↓
RELEASE_READY
```

## Claude 完成后的交接模板

```text
==============================
【当前状态】
正文完成（DRAFT_READY）

【本阶段负责人】
Claude

【已完成】
✓ Draft-v1 正文生成

【下一阶段负责人】
Codex

【需要动作】
运行 validate_reasoning.py 和 Skill007 QA。

【边界说明】
Claude 不执行 QA 裁决，不进入人工审计，不修改发布状态。
==============================
```

```text

审计发现问题（AUDIT_ISSUE）

【本阶段负责人】
Codex / GPT / 人工审计

✓ Evidence / Risk / 修正目标已写入 Audit_Report
✓ Decision_Log 已更新

【下一阶段负责人】
Claude / 写作角色

【需要动作】
按 Audit_Report 执行正文 Patch，生成 Article-Patched-vX.md 和 Patch.diff。

【边界说明】
Codex 不直接改写 Draft / Article / Release 正文；Patch 完成后再交回 Codex 复检。
==============================
```
