# 行为目标参数映射表 V1.0

版本：PARAM-MAPPING-V1.0-BEHAVIOR-GOAL

执行版本：ZH-RUNTIME-V3.0-TEACHER

状态：FROZEN（冻结）

## 核心原则

每篇文章选定唯一的 Primary Behavior Goal 后，所有参数调度围绕该目标进行。

分两层：
- **基础参数**：所有文章必须达标，不因 Goal 而降低
- **Goal 参数**：根据目标重点强化的参数

---

## 基础参数（全文必须 PASS）

这些维度是底线，任何 Goal 都不能牺牲。

| 维度 | 检查内容 | PASS 标准 |
|------|---------|---------|
| 问题回应 | 正文是否真正回答了提问？ | 主线始终围绕提问核心 |
| 推理完整 | 因果链是否成立？ | 至少 3 层推导，终点明确 |
| 阅读顺畅 | 用户是否能不掉队？ | 无被动语态堆砌、无跳跃式转折 |
| 可信度 | 是否有事实支撑？ | 具体场景或例子，无绝对表述 |

## Goal 参数映射

### Goal 1：点赞

**用户为什么点赞**（已有平台证据）
- 共鸣：发现自己的想法被准确表达
- 立场确认：价值观被认可
- 情绪命名：找到情绪的准确表达
- 认知反转：改变了对某事的看法

**重点强化参数**

| 参数 | 强化方向 | 实现方式 |
|------|--------|--------|
| 情绪精准性 | 高 | 用准确的词汇命名特定情绪状态 |
| 共鸣点识别 | 高 | 点出读者未必想到但立即认同的点 |
| 立场鲜明度 | 中高 | 清晰表达价值立场，但不激进 |
| 认知反转 | 中 | 改变读者对某现象的既有理解 |
| 结构化程度 | 低 | 可少于 5 段，注重情绪流畅而非逻辑完整 |

**不是降低的维度**
- 推理完整性：仍需因果链，但可以通过细节传递而非显性陈述
- 阅读顺畅：需要保证，不能因为"追求深度"而累读者

---

### Goal 2：收藏

**用户为什么收藏**（已有平台证据）
- 可复用判断：判断标准可用于其他场景
- 可执行方法：有具体可学的做法或框架
- 边界条件：明确何时适用、何时不适用
- 迁移价值：能从一个场景迁移到另一场景

**重点强化参数**

| 参数 | 强化方向 | 实现方式 |
|------|--------|--------|
| 结构化信息 | 高 | 明确分类、编号、判断标准 |
| 可复用性 | 高 | 给出判断公式、决策树、检查清单 |
| 边界条件 | 高 | 明确适用范围、前置条件、失效条件 |
| 迁移价值 | 中高 | 给出 2-3 个应用场景 |
| 案例具体性 | 中 | 不需要特别多，但需要用于验证框架 |
| 情绪感染力 | 低 | 不是主目标，不特别强化 |

**不是降低的维度**
- 可信度：框架必须有证据支撑，不能空中楼阁
- 阅读顺畅：复杂框架要分步展开，不能一次塞太多

---

### Goal 3：评论

**用户为什么评论**（已有平台证据）
- 冲突：发现可以反驳或延伸的点
- 身份代入：看到自己的角色或立场
- 争议：题目本身有开放性，有表达空间
- 未封口的判断：正文没有说完，留了空间

**重点强化参数**

| 参数 | 强化方向 | 实现方式 |
|------|--------|--------|
| 观点开放性 | 高 | 不绝对化，给不同立场表达空间 |
| 身份代入度 | 高 | 多个角色视角，让不同身份都能代入 |
| 疑问引导 | 中高 | 通过"但是...""那么..."激发想法 |
| 争议点凸显 | 中高 | 不回避冲突，反而主动呈现多元看法 |
| 结论明确性 | 低 | 可以是"取决于"而非"必然是" |
| 情绪强度 | 中 | 恰当，但不是主驱动 |

**不是降低的维度**
- 推理完整：即使留开放性，也要说清各立场的逻辑
- 问题回应：要回应题目，但可从不同角度

---

### Goal 4：转发

**用户为什么转发**（已有平台证据）
- 替用户表达：代替用户说出想表达的话
- 社交货币：分享能增加自己的信息价值
- 立场输出：通过分享建立或强化某个身份标签

**重点强化参数**

| 参数 | 强化方向 | 实现方式 |
|------|--------|--------|
| 观点鲜明性 | 高 | 立场清晰，能代表分享者的态度 |
| 表达可用性 | 高 | 用语精准，可以直接引用或转述 |
| 身份识别度 | 高 | 分享这篇文能传递出分享者什么身份 |
| 情绪感染力 | 中 | 情绪要准确，激发共鸣或赞同 |
| 细节完整性 | 中 | 不需要所有细节，但核心观点要完整 |
| 保留余地 | 低 | 可以温和，但立场要清晰 |

**不是降低的维度**
- 可信度：观点要有依据，不能是空喊口号
- 问题回应：要回应原问题，不能偏题

---

### Goal 5：关注

**用户为什么关注**（已有平台证据）
- 稳定认知差：作者持续提供超预期的认知
- 作者可信度：作者的判断被反复验证
- 持续价值预期：预期后续内容会有价值

**重点强化参数**

| 参数 | 强化方向 | 实现方式 |
|------|--------|--------|
| 认知深度 | 高 | 提供大多数人没想到的角度 |
| 可信度 | 高 | 每个判断都有充分事实支撑 |
| 判断稳定性 | 高 | 不轻易反转，建立可依赖感 |
| 风格一致性 | 中高 | 这篇与之前的内容有明确的风格认可 |
| 情绪表达 | 低 | 不是主驱动，但要显示真实性 |
| 多角度性 | 低 | 不需要多角度平衡，可以有强立场 |

**不是降低的维度**
- 推理完整：判断必须经得起推敲
- 阅读顺畅：高深度不等于难懂，结构要清晰

## 参数调用规则

1. **每篇文章先确定 Primary Goal**
   - 只能一个，不能多选
   - 必须在 Production Card 中完整填写"目标动作理由、触发机制、出现位置"

2. **基础参数检查（前置）**
   - 所有 Goal 都必须检查
   - 任何一项 FAIL，整体 FAIL
   - 不因 Goal 而降低标准

3. **Goal 参数检查（后续）**
   - 根据 Goal 重点检查表中的"强化方向"
   - 强化方向 HIGH 的参数必须 PASS
   - 强化方向 LOW 的参数不是主审核项，但也不能极度缺失

4. **禁止牺牲项检查**
   - Production Card 中勾选的"禁止牺牲项"必须在正文中真正体现
   - 例如勾了"阅读顺畅"，就不能为了深度而让正文难读
