# Semantic Freeze Gate v1

## Reality Freeze

很多中层能带团队、拿结果、管好一块业务，但长期无法进入高层。

## Main Cognitive Gap Freeze

读者以为从中层到高层是管理能力继续升级。实际变化是评价对象变了：中层看确定任务的交付，高层看不确定局面下的取舍、资源排序和系统后果承担。

## Cognitive Conversion Freeze

从“我是不是还不够强”转换为“我是否还停留在高级执行负责人角色里”。高层不是更大的中层，而是组织取舍的承担者。
