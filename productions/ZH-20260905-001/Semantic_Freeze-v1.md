## QT-QI

QT-00 题型判断：判断工具题 / 职场组织观察题。它不是单纯定义领导力，也不是管理学概念科普。

QI-01 提问动机：读者想知道现实中怎样判断一个人是否具备领导能力，尤其是如何识别身边的人、上级或自己有没有领导潜质。

QI-02 真实问题：不是「领导有哪些能力」，而是「现实场景里，哪些行为信号最有识别价值」。

QI-03 当前认知：读者容易用气场、口才、强势、担当、判断力、沟通能力、情商等抽象标签判断领导力。

QI-04 认知缺口：抽象特征不能直接帮助读者识别人。真正需要的是可观察的现场测试。

QI-05 认知目标：把判断标准从「他有没有领导特征」切换为「组织失序时，他是否成为降低不确定性、组织行动、承接责任的事实节点」。

QI-06 阅读奖励：读者读完后能用一个现场测试回看公司里的具体人：出事时，大家向谁寻求判断；那个人又是否真的接住了问题。

## Reality

组织正常运行时，职位、流程和任务说明会替人解决很多问题。此时很多人都能看起来像领导：会开会、会安排、会表达、能控场。

但当任务没人负责、部门互相扯皮、领导不在、信息不完整、利益冲突、责任模糊时，制度和职位暂时不能自动解决问题。团队会本能寻找能降低不确定性的人。

这个时刻更容易暴露真实领导能力。

## Main Gap

旧框架把领导力写成能力清单，问题在于它正确但不可识别。

新框架的缺口不是继续补充能力名词，而是给出行为诊断链：

```text
混乱出现
→ 大家向谁寻求判断
→ 他能否定义问题
→ 他能否组织行动
→ 他是否愿意承担结果
```

## Transformation

读者原本以为：

```text
领导力 = 判断力 + 担当 + 沟通 + 识人 + 决策
```

正文要转换为：

```text
领导力 = 在组织自动运行失效时，成为别人自发信任的决策节点，并把不确定性转成行动和责任。
```

## Core Judgment

判断一个人有没有领导能力，不要先看他像不像领导，而要看局面失控、责任模糊、利益冲突时，别人会不会本能地问他「你觉得现在怎么办」，以及他接住这个问题以后，能不能定义问题、组织行动、承担结果。

## Decision Boundary

- 不写领导力五大特征、七个能力、三种素质等清单。
- 不把「大家愿意听他」直接等同于领导力；这可能只是资历、人缘、业务能力、老板信任或嗓门大。
- 必须补上接住问题后的行为链。
- 不把领导力神秘化为人格魅力。
- 不写成纯鸡汤或个人成长自嗨。
- 不引入未核验的名人案例。
