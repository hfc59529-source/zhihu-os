## Failure Attribution

旧框架疑似路径：

```text
领导力
→ 拆成若干人格/能力特征
→ 判断力、担当、沟通、识人、用人、决策、情商
→ 分别解释
```

失败归因：

```text
Trait Definition 替代了 Behavioral Diagnosis。
```

它告诉读者领导应该有什么，却没有告诉读者现实中怎么把这个人认出来。

这些特征大多正确，但识别价值低。读者无法在现实里给一个人的判断力、担当、沟通力分别打分，然后得出「适合当领导」的结论。

## Intervention Variable

本次干预只锁定解释框架，不把实验解释归因到单纯文案润色。

旧框架：

```text
判断他像不像领导
→ 抽象能力清单
→ 特征定义
```

新框架：

```text
不判断他像不像领导
→ 观察组织失序场景
→ 看团队向谁寻求判断
→ 看此人如何承接不确定性
→ 行为诊断
```

核心变量差异：

- 观察对象从「他有什么特征」改为「别人如何在混乱中对待他」。
- 判断依据从「能力名词」改为「现场行为链」。
- 读者收益从「知道领导力定义」改为「能马上识别一个人是否具备领导潜质」。

## New Behavioral Chain

行为链必须锁定为：

```text
混乱出现
→ 大家向谁寻求判断
→ 谁能定义问题
→ 谁能组织行动
→ 谁愿意承担结果
```

三个连续行为：

1. 定义问题：别人争谁的错时，他能否指出真正卡点，并把局面从追责拉回下一步决策。
2. 组织行动：他不仅自己知道怎么办，还能让销售、财务、生产等不同利益方形成暂时可执行方案。
3. 承接责任：风险出现时，他不把自己退回「我只是建议」，而愿意承担自己推动过的判断和结果。

## Stronger Signal

最干净的领导力信号不是「没有头衔」，而是：

```text
权力可以制造服从，却很难制造自发信任。
```

一个人当了经理后，下属听他的，信息量较低。因为他有考核权、资源分配权、奖金影响力和晋升影响力。

更干净的观察场景是：他没有任免权、考核权、预算，甚至不是项目负责人；但事情一乱，大家仍然本能地问他：

```text
你觉得现在怎么办？
```

但「大家都问他」不能直接等于领导力。还要继续看他接住问题后，是否完成定义问题、组织行动、承接责任。

## Locked Opening Direction

正文开头方向已锁定，但暂不生成正文：

```text
判断一个人有没有领导能力，别看开会。

看出事。
```

首屏必须进入组织失序场景：

- 没人知道怎么办的时候；
- 大家都不愿意负责的时候；
- 几个人利益冲突，谁都不愿意让的时候。

核心判断：

```text
职位告诉你谁是领导。
混乱才告诉你，谁有领导能力。
```

## Personal Stakes

读者读完后应自然回忆并判断：

- 我现在的领导到底有没有领导力？
- 我身边谁其实有领导潜质？
- 我自己是不是那个在混乱中被别人询问「你觉得怎么办」的人？
