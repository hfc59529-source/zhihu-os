# Reasoning Path v1

## Core Question

老板绕过中层直接给基层下指令，中层如何处理？

## Reasoning Path

1. 先承认老板越级指挥不一定都要立刻阻止。有时是急事，有时是老板习惯，有时是培养基层，有时才是架空。
2. 中层真正危险的不是老板说了什么，而是自己不知道老板说了什么、下属按什么标准做、出了问题谁补。
3. 所以处理重点不是争回所有指挥权，而是保证信息和责任不断链。
4. 对老板：不说“不要绕过我”，而说“您直接安排没问题，我把标准、资源和风险接住，免得下面做偏”。
5. 对下属：不说“以后不准越级”，而说“老板交代的事同步我，我帮你确认口径，避免你被反复返工”。
6. 对自己：把每次越级指令变成管理闭环，记录任务、标准、资源、进度和风险，让老板看见中层减少的是他的沟通成本。

## Answer Boundary

不写成：

- 老板不该越级。
- 中层要立威。
- 基层不懂规矩。
- 直接找老板摊牌。

要写成：

- 指令可以越级，信息和责任不能断链。
- 中层的价值不是挡在老板和基层之间，而是把越级带来的混乱重新接回管理链条。
